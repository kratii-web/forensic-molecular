# Running the Project

Currently, it appears there is only a `frontend` folder containing a React/Vite application. No specific backend application code was found in the workspace root.

## Running the Frontend

1. Open a terminal.
2. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```
3. Install the dependencies (if you haven't already):
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```

## Running the Backend

*Note: No backend folder was found in the current directory (`c:\Users\ADMIN\Downloads\stitch_forensic_molecular_lims`).*

If you do have a backend (e.g., Node.js/Express, Python/Django, etc.) located somewhere else or if you add one later, you would typically follow these steps:

1. Open a new terminal window.
2. Navigate to your backend directory (e.g., `cd backend`).
3. Install backend dependencies (e.g., `npm install` for Node.js, `pip install -r requirements.txt` for Python).
4. Start the backend server (e.g., `npm start` for Node.js, `python app.py` for Python).

## Running Both Together

To run both, you simply need to have two separate terminal windows open:
- One running `npm run dev` in the `frontend` folder.
- One running the start command in your `backend` folder.
